# Taskly.Contracts

The shared vocabulary of Taskly: the enums the host and the seed are written in, with no
dependencies of its own.

| Folder | What it holds |
| --- | --- |
| `Enums/Issues` | Issue status, type, priority and the other properties of a task |
| `Enums/Projects` | Project status |
| `Enums/Notifications` | Notification kinds and system task states |
